# Ramas (branches)

## 📌 Sobre esta carpeta

Todavía no he trabajado con ramas en un proyecto real — en mis repos de ejercicios (`Temario-Java`, `Temario-HTML`) no tiene sentido usarlas, porque son ejercicios lineales sin riesgo de romper nada.

Esta carpeta se rellenará cuando:
- Empiece algún proyecto donde tenga sentido probar cosas en una rama aparte antes de mezclarlas a `main` (por ejemplo, el proyecto `SurfCamp Manager` de clase, o algo de práctica libre en Java más adelante).
- Lo vea aplicado en el libro de Brais Moure o en el curso de DevTalles.

## 🧩 Lo que sé por ahora (teoría, pendiente de aplicar)

| Comando | Para qué sirve |
| :--- | :--- |
| `git branch` | Listar las ramas que existen |
| `git checkout -b nombre-rama` | Crear una rama nueva y moverme a ella |
| `git checkout nombre-rama` | Cambiar a una rama ya existente |
| `git merge nombre-rama` | Traer los cambios de una rama a la rama en la que estoy |
